# CheckPoint #1 — идея проекта

**Кейс:** «Агент-декомпозитор» (Элара).

**Идея.** Агент берёт эпик на интеграцию, документацию на внешнюю систему и её API-контракт
(gRPC `.proto` / OpenAPI) и раскладывает эпик на требования, пользовательские истории
и технические задачи. Это **не генератор задач, а проверка полноты интеграции**: каждая задача
обоснована ссылкой на источник (раздел документа, метод контракта), а непокрытые требования
и пробелы в контракте видны до того, как их найдёт заказчик.

**Как работает:**
- Модель работает **в замкнутом контуре**, как на вашей схеме: Bitbucket → Webhook → LangGraph →
  HAProxy → vLLM + Qwen3.8. Модель подключается через прослойку, её можно заменить. Промпты
  лежат в отдельных файлах, их можно настраивать.
- Конвейер агентов: разбор контрактов → требования → уточняющие вопросы → истории → задачи →
  проверка (код ловит выдуманные API и считает покрытие, критики-LLM проверяют качество).
- Результат выгружается в DOCX / XLSX / JSON со статистикой и автоматически создаётся в Jira:
  Epic → Story → Sub-task с меткой `<Эпик>_Autogenerate`. Запуск — из веб-интерфейса
  или по `git push` эпика в Bitbucket.
- Сравнение с итоговым перечнем задач команды: что совпало, что пропущено, и рекомендации
  по промпту. Это и проверка работы аналитика.
- Веб-интерфейс с 3D-визуализацией: декомпозиция собирается вживую, клик по задаче
  показывает её источник.

**Стек:** Python (FastAPI, LangGraph), React + three.js, vLLM / llama.cpp, Jira Cloud, Bitbucket Cloud.
