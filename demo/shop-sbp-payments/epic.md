# Оплата через СБП

Сейчас магазин «Полка» принимает только оплату картой через paymentservice. Покупатели
просят оплату через Систему быстрых платежей: она дешевле для магазина и привычна людям.
Нужно подключить оплату по QR-коду СБП через банк-эквайер «Восход».

Что должно получиться:

- На странице оплаты покупатель может выбрать «Оплатить через СБП» и видит QR-код
  (на телефоне — кнопку перехода в приложение банка).
- У покупателя есть 15 минут, чтобы оплатить заказ по QR-коду.
- Как только деньги поступили, заказ автоматически переходит в статус «Оплачен»,
  а покупатель получает письмо-подтверждение.
- Одна оплата — один заказ: заказ не должен оплачиваться дважды, даже если покупатель
  отсканировал код повторно или сеть дала сбой.
- Оператор может вернуть деньги за заказ, оплаченный через СБП, полностью или частично.
  Покупатель получает деньги обратно не позже чем через минуту после возврата.
- Если банк «Восход» недоступен, покупатель по-прежнему может оплатить картой, а кнопка
  СБП временно скрыта.
- Все обращения к API банка и ошибки фиксируются в журнале.

Ограничения:

- Ключи доступа к API банка хранятся в секретах Kubernetes, а не в коде.
- Страница оплаты не должна открываться медленнее, чем сейчас, больше чем на 300 мс.
