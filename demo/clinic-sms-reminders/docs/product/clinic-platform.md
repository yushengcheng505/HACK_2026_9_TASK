# Платформа клиники «Здоровье+»

Сервисы на C# (.NET 8), общаются по gRPC внутри кластера Kubernetes.

## Сервисы

- **webportal** — личный кабинет пациента и интерфейс администратора.
- **appointmentservice** — расписание и записи на приём (`appointments.proto`): создание,
  перенос, отмена, освобождение слота. Хранит записи в PostgreSQL (таблица `appointments`).
- **notificationservice** — все сообщения пациентам. Сейчас отправляет только письма:
  раз в 10 минут фоновая задача выбирает записи на ближайшие сутки и отправляет напоминания.
  Отправленные напоминания отмечает в своей таблице `reminders` (PostgreSQL).
  Другие сервисы к внешним каналам связи напрямую не обращаются.

## Эксплуатация

- Секреты — Kubernetes Secrets, в сервисы попадают через переменные окружения.
- Логи — stdout в формате JSON, собираются в Loki.
- Входящие запросы из интернета принимает только ingress с путями `/portal` и `/hooks`.
