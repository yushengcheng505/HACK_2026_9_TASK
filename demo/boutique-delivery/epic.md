# Интеграция с курьерской службой «Курьер-Экспресс»

Сейчас Online Boutique считает стоимость доставки по фиксированной формуле в shippingservice
и выдаёт выдуманный трек-номер. Покупатели не видят реальных сроков и не могут отследить заказ.
Нужно подключить внешнюю курьерскую службу «Курьер-Экспресс» через её API.

Что должно получиться:

- При оформлении заказа покупатель видит реальную стоимость и срок доставки по своему адресу,
  рассчитанные «Курьер-Экспресс».
- Покупатель может выбрать курьерскую доставку до двери или самовывоз из пункта выдачи.
- После оплаты заказа автоматически создаётся отправление в «Курьер-Экспресс», и покупатель
  получает настоящий трек-номер в письме-подтверждении.
- Если при создании отправления пропала связь или курьерская служба ответила ошибкой,
  создание повторяется автоматически. При этом один заказ не должен превращаться в два отправления.
- Покупатель получает уведомление об изменении статуса доставки (передан курьеру, доставлен)
  не позже чем через минуту после изменения.
- Покупатель может отменить заказ, пока отправление не передано курьеру; тогда отправление
  в «Курьер-Экспресс» тоже отменяется.
- Оператор магазина видит в журнале все обращения к API курьерской службы и их ошибки.

Ограничения:

- Ключ API «Курьер-Экспресс» хранится в секретах Kubernetes, не в коде.
- Время ответа страницы оформления заказа не должно вырасти больше чем на 500 мс.
- Если «Курьер-Экспресс» недоступна, оформление заказа не блокируется: показываем стоимость
  по старой формуле с пометкой «предварительно».
