# Пульт оператора — дизайн

Отдельная страница фронтенда для работы с агентом-декомпозитором. Лендинг «Стая» не меняется.

**Прочтение задачи:** рабочий пульт для аналитика, техлида и жюри на демо. Тёмный интерфейс
«телеметрии» в фирменных цветах «Стаи», нативный CSS + SVG, без новых зависимостей.
Ручки дизайна: разнообразие 5, движение 6, плотность 7.

## Главная идея
Показать **прослеживаемость**: каждая задача обоснована требованием, требование — источником.
Центральная сцена — трассировочная карта из четырёх колонок
`Источники → Требования → Истории → Задачи`. Она собирается вживую по событиям SSE.
Клик по любому узлу подсвечивает его цепочку вверх и вниз и показывает текст источника.

## Визуальный язык
- Подложка — `ink` с лендинга и тонкая чертёжная сетка. Плоские панели с линиями в 1px (`gap: 1px`
  на фоне `line`), углы 2px. Без градиентов-«облаков» и стекла.
- Акцент — фирменный `brand` (зелёный люминофор): активное, покрытое, «принято».
  Красный `hazard` — только ошибки, выдуманные ссылки и пробелы. Янтарный `amber` — предупреждения
  (нет интеграционного теста). Пунктир — «не задействовано, подтвердите».
- Шрифты лендинга: Unbounded — крупные цифры метрик и заголовки, JetBrains Mono — ID, статусы,
  подписи (капс, разрядка), Manrope — тексты требований и задач.
- ASCII-рамки в подписях: `[ ТРЕБОВАНИЯ ]`, `>>>`, `REV`, `ID`.

## Движение
Каждая анимация отвечает на вопрос «что сейчас делает агент»:
- рельс конвейера: активный узел пульсирует, по рельсу бежит луч; петля критика рисуется дугой
  с номером круга;
- новые узлы карты въезжают (opacity + translateY 6px, 220 мс, ease-out, лесенка 40 мс);
- новая связь прорисовывается (stroke-dashoffset, 500 мс); у выбранной цепочки по связям бегут импульсы;
- счётчики метрик докручиваются до значения;
- замена задач после критика: старые гаснут и зачёркиваются, новые въезжают.
Короткие длительности, свои кривые (`cubic-bezier(0.23, 1, 0.32, 1)`), `prefers-reduced-motion`
отключает смещения и импульсы. Наведение и частые действия не анимируются.

## Экраны
1. **Запуск** — галерея демо-эпиков (`GET /api/demos`) и форма своего эпика: название, текст,
   четыре зоны файлов (документация продукта, смежной системы, контракты, примеры; без PDF),
   переключатель «без вопросов».
2. **Прогон** (главный):
   - шапка: эпик, метка `_Autogenerate`, статус, модель, хост LLM, таймер;
   - метрики: требования, истории, задачи, пробелы, покрытие %;
   - рельс конвейера: Разбор → Язык → Требования → Аналитик → Вопросы → Истории → Задачи →
     ОТК → Критик (петля к Задачам) → Сборка;
   - вкладки: **Карта** | **Таблица** (правка → `PUT /result` → пересчёт проверок) |
     **ОТК** (замечания и покрытие контракта) | **Пробелы**;
   - инспектор справа: выбранный узел, его связи, текст источника, DoD, тест-сценарии;
   - телеметрия снизу: поток рассуждений и ответа модели по узлам, журнал событий;
   - вопросы аналитика: при `waiting_answers` поверх карты встаёт панель с вариантами, своим
     ответом и «Пропустить»;
   - выгрузка DOCX / XLSX / JSON, «Проиграть запись» (`?replay=1`).
3. **Запуски** — история с метриками и статусами.

## Архитектура
- Вторая точка входа Vite: `frontend/console/index.html` → `src/console.tsx` → `app/ConsoleApp`.
  В `vite.config.ts` — многостраничная сборка и прокси `/api` на бэкенд `:8000`.
- Слои FSD как на лендинге: `pages/console`, `widgets/{console-shell,launch-panel,run-header,
  pipeline-rail,trace-map,inspector,telemetry,questions-panel,results-table,qc-report,runs-list}`,
  `features/{run-stream,launch-run,answer-questions,edit-result,export-run}`,
  `entities/run` (типы событий и результата, редьюсер), `shared/api`.
- Состояние прогона — чистый редьюсер `applyEvent(state, event)`: из потока SSE строится модель
  карты. После `run_finished` подтягивается полный результат (`GET /api/runs/{id}`).
- Маршрут в хеше: `#/` — запуск, `#/runs` — история, `#/run/<id>` — прогон.
- Связи карты — SVG поверх колонок; координаты берутся из DOM (`ResizeObserver`), карта
  прокручивается целиком, поэтому связи не съезжают.

## Проверка
`npm run build` и `npm run lint` чистые. Скриншоты headless-браузером: запуск, прогон в процессе
(проигрывание записи), выбранная цепочка, вопросы, таблица, ОТК.
Лендинг `/` открывается без изменений.
